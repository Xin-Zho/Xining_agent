记忆系统代码架构

SQLite + ChromaDB · BGE 嵌入 · 零外部服务

📁 文件结构

backend/memory/
memory/
├── __init__.py            → 暴露 MemoryManager, get_memory_manager()
├── base.py              → BaseMemory(ABC) + MemoryItem + MemoryConfig
├── manager.py           → MemoryManager 统一调度（入口）
├── working.py          → WorkingMemory — 会话层，纯内存 dict + TTL
├── episodic.py        → EpisodicMemory — 任务事件，SQLite + ChromaDB
├── semantic.py        → SemanticMemory — 偏好/知识，SQLite + ChromaDB
├── embedding.py       → LocalEmbedding（BGE 模型）
├── long_term.py        → [deprecated] 内部迁移到 semantic
└── tools/
    ├── __init__.py
    ├── memory_tool.py   → MemoryTool（第一期，LLM 调用入口）
    └── rag_tool.py       → RAGTool（第二期，空壳占位）

🏗️ 类层次结构

Class Hierarchy
BaseMemory (ABC)
├── WorkingMemory  → 存储: dict{user_id: deque}, TTL 自动过期
├── EpisodicMemory → 存储: SQLite + ChromaDB Collection
└── SemanticMemory → 存储: SQLite + ChromaDB Collection

MemoryItem (dataclass)
└── content, memory_type, importance, timestamp, metadata, ttl

MemoryConfig (dataclass)
└── working_capacity, episodic_ttl, semantic_consolidation_threshold...

MemoryManager
├── __init__(user_id, config, embedding, chroma_client)
├── add(content, type, importance) → 路由到对应记忆类型
├── search(query, memory_types, limit) → 混合检索
├── consolidate() → Working→Episodic→Semantic
├── forget(strategy) → 重要性/时间/容量遗忘
└── get_context_for_prompt() → 拼接注入 System Prompt

LocalEmbedding
├── __init__(model_name="BAAI/bge-small-zh-v1.5")
└── embed(texts: list[str]) → np.ndarray

🔄 数据流

请求生命周期
┌─────────────────────────────────────────────────────────┐
│  1. LLM 调用 memory_tool(action="save", content="用户喜欢Python")
│  2. MemoryTool.execute() → MemoryManager.add()
│  3. MemoryManager 调用 LLM 分类:
│       "用户喜欢Python" → semantic(偏好), importance=0.7
│  4. SemanticMemory.add():
│       a. 写入 SQLite（source of truth）
│       b. embed() → 向量写入 ChromaDB
│  5. 返回确认给 LLM
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  1. LLM 调用 memory_tool(action="search", query="编程偏好")
│  2. MemoryTool.execute() → MemoryManager.search()
│  3. embed("编程偏好") → 查询向量
│  4. ChromaDB 语义检索 (episodic + semantic 两个 collection)
│  5. 按评分公式排序: (相似度×0.7 + 重要性×0.2 + 时间×0.1)
│  6. 返回 top-N 给 LLM 作为上下文
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  引擎层注入（每次 Agent 任务启动时）:
│  1. MemoryManager.get_context_for_prompt()
│  2. Working: 当前会话上下文（最新 N 条）
│  3. Semantic: 用户偏好和长期知识（重要性 > 阈值）
│  4. 拼入 System Prompt → LLM 推理
└─────────────────────────────────────────────────────────┘

Storage Map
数据存储位置用途

Episodic 向量ChromaDB语义检索
Semantic 记忆原文SQLite (memory.db)source of truth
Semantic 向量ChromaDB语义检索
