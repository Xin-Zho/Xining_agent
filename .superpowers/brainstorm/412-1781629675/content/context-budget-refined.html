🕐 时间分窗策略

同一会话内的对话历史处理
完整保留
压缩摘要（不丢弃）
超阈值 → 全量压缩
区域条件处理示例
热窗口最近 3~5 min 内完整保留原文正在追问、纠错、连续指令
温窗口同会话，超过 5 minLLM 摘要压缩，保留关键信息10分钟前的搜索结果、已完成的子任务
压缩触发历史 tokens > HISTORY_BUDGET把所有已压缩摘要 + 温窗口 → 再压成一段超长会话（50+轮），兜底保护

🔄 完整流程

ContextBuilder.build() 逻辑
def build(messages, memories, hot_window_sec=180):

  # 1. 切分对话历史
  now = time.time()
  hot_msgs  = [m for m in messages if now - m.ts < hot_window_sec]  ← 完整保留
  warm_msgs = [m for m in messages if now - m.ts ≥ hot_window_sec]  ← 待压缩

  # 2. 压缩温窗口（同一会话，不丢弃）
  if warm_msgs:
    summary = llm.summarize(warm_msgs)   ← 生成摘要
    compressed_block = f"[会话早期摘要]\n{summary}"

  # 3. Token 总量检查（兜底）
  total = estimate_tokens(system) + estimate_tokens(memories)
         + estimate_tokens(hot_msgs) + estimate_tokens(compressed_block)
  if total > HISTORY_BUDGET:              ← 兜底阈值
    compressed_block = llm.summarize(compressed_block + hot_msgs[:-2])
    hot_msgs = hot_msgs[-2:]               ← 只保留最近2轮

  # 4. 记忆上下文
  mem_ctx = MemoryManager.search(query, top_k=5)
  if estimate_tokens(mem_ctx) > total * 0.15:  ← 不超过总预算 15%
    mem_ctx = mem_ctx.truncate_to(total * 0.15)

  # 5. 组装
  return [system] + [mem_ctx] + [compressed_block] + hot_msgs + [task]

参数默认值含义

场景热窗口温窗口兜底压缩
短会话（5轮，2分钟）全部保留无不触发
中会话（20轮，15分钟）最近5轮前15轮→摘要不触发
