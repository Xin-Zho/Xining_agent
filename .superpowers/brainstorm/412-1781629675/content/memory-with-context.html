🎯 ContextBuilder 职责

context.py — 上下文工程层
class ContextBuilder:
  """把记忆+历史+任务 组装进 LLM 上下文窗口，不超预算"""

  budget       = 90_000    # 总 token 预算
  system_reserve = 3000     # System Prompt 固定配额
  memory_budget  = 2000     # 记忆上下文最大 token
  history_budget = 60_000   # 对话历史最大 token
  tool_budget    = 25_000   # 工具结果最大 token

  # 核心方法
  build(memories, history, task) → list[dict]
    """主入口：组装最终 messages"""
    1. 按 query 相关性排序记忆
    2. 截断记忆到 memory_budget
    3. 压缩旧对话到 history_budget
    4. 按 [System + 记忆 + 历史 + 任务] 组装

  rank_memories(memories, query) → list[MemoryItem]
    """按查询相关性+重要性+时间排序"""

  compress_history(messages, budget) → list[dict]
    """把旧消息摘要压缩（复用现有逻辑）"""

  format_memory_context(memories) → str
    """记忆→结构化文本块，注入 prompt"""

  truncate_tool_result(text) → str
    """工具结果智能截断（头尾保留）"""

🏗️ 更新后的类关系

三大核心类协作
MemoryManager    → "存什么、查什么"
  .add() .search() .consolidate() .forget()

ContextBuilder   → "给 LLM 塞什么、塞多少"
  .build() .rank_memories() .compress_history() .format_memory_context()

MemoryTool       → "LLM 怎么调用"
  Tool 接口，委托给 MemoryManager
